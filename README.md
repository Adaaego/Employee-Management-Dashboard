# Employee Management Dashboard

A responsive, front-end employee management dashboard built with **HTML**, **CSS**, and **JavaScript**. The project features a secure login page, progress tracking, theme toggle (light/dark mode), and a clean UI using Flexbox and Grid.

## 🔐 Login Page

- The app begins with a **login screen**.
- Only users listed in a predefined **JavaScript data array** can log in.
- After login, users are taken to the dashboard.

## 🌗 Theme Toggle

- Users can switch between **Dark Mode** and **Light Mode** to suit their visual preference.

## 📊 Dashboard Features

- **Project cards** display basic project information and progress percentages.
- Each project shows visual **progress bars** to track completion status.
- Projects and layout are built using **CSS Flexbox** and **Grid** for structure and responsiveness.

## 🧱 Layout & Design

- Fully responsive design using:
  - **Flexbox** for general layout and spacing
  - **CSS Grid** for the dashboard structure
- Minimal, modern UI designed for clarity and ease of use

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
